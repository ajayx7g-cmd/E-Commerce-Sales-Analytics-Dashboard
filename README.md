An interactive E-Commerce Sales Analytics Dashboard built using Microsoft Power BI to analyze revenue, orders, sales trends, payment methods, shipping costs, and order performance through dynamic visualizations and filters.

# 📊 E-Commerce Sales Analytics Dashboard

### Power BI | Data Analytics | Business Intelligence

## 📌 Project Overview

This project presents an interactive E-Commerce Sales Analytics Dashboard developed using Microsoft Power BI.

The dashboard provides insights into overall sales performance, customer orders, revenue trends, payment methods, shipping costs, and order delivery status.

It helps transform raw e-commerce data into meaningful business insights through interactive visualizations.

- Monitor order delivery status.

## 📈 Dashboard Features

**1. Sales by City**

Displays sales performance across different cities using a horizontal bar chart.

**2. Sales by Year**

Visualizes yearly revenue trends from 2024 to 2026 using a line chart.

**3. Payment Method Analysis**

Analyzes payment distribution across:

- UPI
- Cash on Delivery (COD)
- Debit Card
- Credit Card

**4. Order Status Analysis**

Tracks order quantities across Delivered, Cancelled, Processing, Returned, and Shipped categories.

**5. Interactive Filters**

Users can dynamically filter dashboard information using:

- State
- Year
- City

## 💡 Key Insights

- Total revenue reached 5,930.69M.
- Approximately 250K orders were recorded.
- Sales peaked in 2025.
- UPI contributed the highest payment value.
- Delivered orders accounted for the largest order-status category.
- Madurai and New Delhi were among the leading cities by sales.
